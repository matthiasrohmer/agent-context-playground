Guided Scenarios for Agent Context Comments

Three structured scenarios covering all supported DevTools comment surfaces: the Elements panel, the Network panel, and the Sources panel.

Scenario 01 Elements Panel · DOM & CSS

DOM & Styling — Restyle Button or Fix Distorted Logo

Verify that anchoring a comment to a DOM element in the DevTools Elements panel gives your coding agent the exact node context needed to update CSS or markup.

How to Test:

  1. Right-click the crimson button (or the stretched logo badge) below and select Inspect to highlight it in the DevTools Elements panel.
  2. Click the Comment Mode icon in the top-left DevTools toolbar and click the highlighted DOM node row (e.g. <button id="starter-target-btn">).
  3. Add a comment such as change button to blue or fix the distorted aspect ratio of this logo.
  4. Click Send to Agent in the DevTools Comments drawer (or ask your coding agent: respond to my comments).

Scenario 03 Sources Panel · Line-Level Code Comments

Source Code Debugging — Fix the Promo Discount Calculation Bug

Test line-level comments in the DevTools Sources panel by anchoring feedback directly to a buggy JavaScript function in app.js.

How to Test:

  1. Click Apply 20% Promo (DEVTOOLS20) on the right — notice the bug: the total increases from $100.00 to $120.00 instead of dropping to $80.00.
  2. Open the DevTools Sources panel, select app.js, and locate the calculateDiscountedTotal function.
  3. Enable Comment Mode, click the buggy formula line in app.js, and leave a comment: fix the discount calculation so it subtracts the discount amount instead of adding it.
  4. Click Send to Agent in the Comments drawer and verify the updated calculation.
